SPEED NOTES (speed rework)
==========================

Rules
-----
- Each Zoid's canon top speed comes from the Zoids Wiki (zoids.fandom.com),
  infobox "Speed" field, read 22 Oct 2026. Sources per Zoid are listed below.
- One scale for everything: 1 canon km/h = 0.11 m/s in game (SPEED_SCALE in
  js/catalog.js). Maps are metre-scale but small, so real speeds would cross a
  map in seconds; this keeps relative speeds exactly canon while playable.
  The HUD and hangar show the canon-equivalent figure (game m/s / 0.11).
- Standard (stock) speed = half canon top speed.
- Speed Boosters: 3 levels, each +33% of STANDARD speed (additive), capped at
  2x standard. 0/1/2/3 levels = 1.00x / 1.33x / 1.66x / 2.00x. The 3rd level
  hits the cap, so the full set is exactly canon top speed. A 4th level can't
  be bought (MODS.speed.max = 3) and any higher value is clamped to 2x.
  The shop previously had 2 levels of +8%; it now has 3 levels costing
  24,000 / 52,000 / 90,000 C (weight 4 t per level, unchanged).
- Tonnage-zone slowdowns (js/tonnage.js) and leg damage apply after the
  upgrade multiplier, to both top speed and acceleration/braking.

Acceleration
------------
- Each Zoid has accel (m/s^2 when speeding up) and brake (slowing/reversing,
  1.3x accel). Both are multiplied by the tonnage zone's accel factor and drop
  with leg damage. AI Zoids use 85% of the same values.
- Command Wolf and Zaber Fang (saber/tiger type) have the highest acceleration.
  Everything else is lower, scaled by weight and canon top speed.
- Pteras: ground accel 24; in the air it uses its flight thrust (14 m/s^2,
  flight.thrust in the catalog) for gaining airspeed, 1.3x that to slow down.
- Hangar "0-100" = seconds from rest to 100 km/h-equivalent at the current
  load (or to the Zoid's top speed if that is lower, e.g. stock Gojulas).
  Game-scale times are short because game speeds are scaled down too.
- Zaber Fang is in the catalog already (no new model was built); its values
  are the ones listed here.

Units
-----
- Hangar speed stat shows current top speed / max (canon) speed with a
  KM/H / MPH toggle. The choice is saved in localStorage
  (zoidMercs.speedUnit) and the mission HUD uses it (ground and AIR speed).

Compromises
-----------
- Pteras canon is Mach 2 (about 2,450 km/h). That is unplayable on our maps,
  so it is capped at a 600 km/h-equivalent full speed (stock 300). It is still
  the fastest Zoid by far.
- Command Wolf, Gun Sniper and Molga all list 200 km/h, so they share a top
  speed; acceleration and turning separate them.
- Command Wolf is now slower than the Ligers on top speed (canon); its edge is
  the best acceleration.
- Every Zoid now starts at half its old-scale feel until Speed Boosters are
  bought. Enemy Zoids have no Speed Boosters, so they run at standard speed.
- The supply truck (8 m/s) and static structures were left unchanged so the
  escort mission balance holds.
